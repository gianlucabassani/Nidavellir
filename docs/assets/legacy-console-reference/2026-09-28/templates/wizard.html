What are you standing up?

Git targets use an isolated writable checkout and setup phase. OCI targets run their native entrypoint from a registry-verified immutable digest. An optional Kali foothold joins the isolated segment.

The archive is validated without host extraction, stripped of links and special files, hashed, and stored immutably. Setup runs only inside the disposable target.

How it works
Clone — your repo is cloned into /opt/sut on a fresh Ubuntu box.
Isolate — the box sits on its own segment, network-isolated from the host.
Attack — optionally a Kali foothold joins the segment for the engagement.

Setup phase — your consent

Bringing a Git target up needs a configurator session on the victim. Nothing writes/configures the box without it, and it is time-boxed, step-budgeted, and its egress is revoked before the engagement.

Safety guarantees
Time-boxed — the setup session auto-expires after the configured timeout.
Step-budgeted — hard cap on the number of commands that can run.
Egress revoked — network egress is cut before the engagement begins.
