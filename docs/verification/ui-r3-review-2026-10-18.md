# UI-R3 independent code review — 2026-10-18

Review scope: working-tree and new source changes since
`61484067204ee8b5fc7f93535d56a2b05475059e`, against TODO UI-R3, the approved
bounded request-comparison design, AGENTS instructions and API contracts.
The requesting-code-review skill dispatched independent reviewer agents.

Earlier review found four important issues, reproduced with focused regressions:

- Merged-request validation serialized Pydantic input context. The API now returns
  messages only, excluding input/context/URL. This was an unsafe error-format defect;
  no live credential exfiltration was demonstrated.
- Content deduplication retained the first manifest actor and could deny a later
  legitimate capturing actor. Authorization now also accepts a durable successful
  `http_request` receipt for the exact transaction digest and arena.
- Replay-parent and raw-read paths needed the same actor ownership boundary as
  comparison and credential-source reads. All now share that check.
- Dropping all response headers removed useful research evidence. Comparison now
  includes a bounded allowlisted projection and header diff, with cookie values,
  redirect credentials/query values/fragments and unrecognized headers withheld.

The earlier re-review reported no important issues remaining. A fresh independent
review on October 18 inspected the final tracked and new implementation, including
backend replay/ownership, group pagination, gateway, console state and credential
edge cases. It found no blocking defects. Its one minor finding was an inaccurate
“captured bytes” label for the full response size; this was changed to “response
bytes.” Static review explicitly conditioned merge readiness on passing the final
live/release gates and completing delivery records.

Retained scope limits: projected headers omit unknown headers and some cookie
attributes (Domain/Path/expiry); the authorized protected original remains linked.
Truncated captures, clipped previews/diffs and unresolved evidence remain explicit.
This is focused code review, not a repository-wide security audit. Live and release
results are recorded separately in the closure report.
